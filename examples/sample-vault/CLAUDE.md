# CLAUDE.md — Vault

Agent guidance for Claude Code when operating on this vault. Stub for now; populated in Phase 4 when the compile-pass and entity-creation workflows come online.

## Quick orientation

- This is the sample vault. The real operating vault lives in a separate private repo.
- `INDEX.md` is the answer key for recurring questions.
- `CONVENTIONS.md` holds the operating rules — routing decision rule, merge resolution rule, frontmatter contract, naming. Read it before making any structural change.
- `source/` is canonical. `compiled/` is regenerated by scheduled compile passes. `dashboards/` holds Dataview queries rendered at view-time.
- Never write to entity bodies (the prose section of an `index.md`). The worker writes only to frontmatter.
- Never autonomously create entity files. Unmatched entities go to the review queue; creation happens through a Claude Code session with human review.
