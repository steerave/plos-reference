# PLOS Index

This is the answer key. Every recurring question PLOS is built to answer maps here to its surface. For ad-hoc questions not covered below, use a Claude Code session against the vault.

The routing rule that governs this map (Dataview as default; compiled artifact as named exception) is documented in `CONVENTIONS.md`.

---

## Compiled artifacts (regenerated on schedule)

These three answer questions that require synthesis beyond aggregation. Each is regenerated by a scheduled Claude Code compile pass.

- **What needs my attention this week?** → `compiled/this-week.md` *(daily)*
- **What's unusual this month?** → `compiled/anomalies.md` *(monthly)*
- **Tax prep status, missing documents, accountant list?** → `compiled/tax-prep.md` *(weekly Jan–Apr, monthly otherwise)*

## Dataview dashboards (live in Obsidian)

These render at view-time against current frontmatter. Always fresh; no compile cost.

- **What's expiring or due in 30 / 60 / 90 days?** Birthdays and anniversaries? → `dashboards/upcoming.md`
- **Property tax, insurance, carrying cost, mortgage history, utilities — per property?** → `dashboards/properties.md`
- **Where is monthly cash going?** → `dashboards/cash-flow.md`
- **What subscriptions am I paying for monthly?** → `dashboards/subscriptions.md`
- **Family medical state, vaccinations, medications, health insurance coverage?** → `dashboards/medical.md`
- **Vehicle insurance, registration, inspection, service history?** → `dashboards/vehicles.md`
- **Investment account balances and retirement progress?** → `dashboards/investments.md`
- **State of each project and next steps?** → `dashboards/projects.md`
- **Estate gap report — wills, POA, beneficiaries?** → `dashboards/estate.md`
- **Household account access map and recovery paths?** → `dashboards/account-access.md`

## Ad-hoc questions

For one-off analytical questions not covered above — comparisons across years, custom rollups, exploratory queries — open a Claude Code session against the repo. Same client that runs the compile passes and long-tail extraction.
